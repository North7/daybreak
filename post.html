手機：按「分享到 X（含圖）」→ 在分享選單選 X，圖和文字一起帶進發文視窗；若 X 只帶了圖，文字已自動複製，在發文框貼上即可。「存到相簿」→ 選「儲存影像」。「在 X App 發文」直接打開 X App 的發文視窗（只有文字）。
Phone: "Share to X (with image)" → pick X in the share sheet; the text is also copied, so paste it if X keeps only the image. "Save to Photos" → choose "Save Image". "Post in X app" opens the X app composer (text only).
