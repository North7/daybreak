# 圖表風格（2026-11-05 起）

使用者要求：**接下來所有的圖都要儘量做得華麗、抓眼球，方便對外展示（截圖貼到 X、分享）時吸引注意力。**
新做的圖照這份做；舊圖改版或被選去對外分享時，也照這份升級。

## 要做到

1. **大字讀數放最上面**：圖的上方放 1–3 張讀數卡（`.cf-card` 樣式），一眼看到現在的數字、30 天變化（▲▼）、和歷史對照（例如「2017 頂 67%」）。截圖只截卡片和圖也看得懂。
2. **漸層面積＋發光線**：面積用由上往下淡出的漸層（頂端不透明度 0.6–0.7、底部約 0.05），線 2px、加一層淡淡的發光（`feGaussianBlur` 約 2px）。不要用實心大色塊。
3. **歷史對照直接畫在圖上**：週期頂部、熊市底部用淡色底帶（頂部 `--warn`、底部 `--s3`，不透明度約 0.13）；重要峰值用彩色膠囊標籤（年份＋數值），不要每個點都標。
4. **「現在」要搶眼**：最後一點用脈動圓點（`.cf-pulse`，尊重 `prefers-reduced-motion`），旁邊寫「現在 XX%」。
5. **進場動畫**：線用 `animateLines`（畫線動畫），不要太長。
6. **日刊、夜刊都要好看**：顏色只用 `--s1`–`--s4`、`--up`／`--down`、`--warn` 等變數，兩種主題都要截圖檢查；新的類別配色先跑 dataviz 的 `validate_palette.js`（亮、暗兩種背景都要通過）。

## 不變的規矩（華麗不能犧牲正確）

- 一張圖一個 y 軸：價格放上格、指標放下格，共用時間軸，不做雙軸。
- 每張圖都要有「現在」那一行和「怎麼讀這張圖」；推算的數字標「推算」。
- 文字用文字色，不用系列色寫數值（膠囊標籤是例外：白字配系列色底）。
- 手機寬度（390px）要能看：小螢幕時減少標籤、膠囊只留最重要的或不畫。
- 只作讀值，不在圖上寫預測或買賣建議；產品內不寫個人名字。

第一張照這份做的圖：鏈上版「循環資金流：投機 vs 長線」（`cfPanel`／`drawCapflow`）。
