# 指標與圖表點子

運營掃 X 找回覆對象時順手記下的：別人在用、網站還沒有（或可以做得更好）的比特幣指標和圖表。網站那邊要加新模組、新圖之前，先看這裡；同一個指標被越多人提到，越值得做。2026-11-04 開始記錄。

## 怎麼記

- **只記數據指標和圖表**，不記價位、喊單、交易策略、帶單工具。
- **先確認網站有沒有**：查 `data/latest.json` 的欄位，或 `pipeline/collect.py`、`pipeline/signals.py`、`pipeline/picks.py`。已經有的不重記；呈現方式可以改進的，記在「已有、可以改進」。
- **每則寫清楚**：誰、哪天、連結；指標是什麼、他怎麼用；資料從哪來（免費嗎、要不要金鑰）；我們可以怎麼做。
- **重複出現**：同一個指標又有人提，「次數」加一，在「誰在用」補上連結，不要另開一列。
- **做完或決定不做**：移到最後的「已處理」，寫一句原因或做在哪裡。
- 跟網站其他東西一樣：只作讀值，不標買賣區、不連動任何規則。
