# 參考帳號：什麼樣的貼文有人看

2026-11-04 用內建瀏覽器讀各帳號個人頁最近的貼文整理（瀏覽數是當天讀到的）。用意是收集參考、找出可以借用的寫法，不是照抄。每隔一兩個月重看一次，新增的帳號也照這個格式記。

## Murphy（@Murphychen888，約 8.2 萬粉）

讀了 46 則（10/24–11/04）。

| 類型 | 瀏覽 |
|---|---|
| 公開的數據貼文（一則一張圖） | 多半 1.2 萬–8.5 萬 |
| X 長文（問句標題，例如「跌破 80K，潛在拋壓有多大？」） | 2.5 萬–4.2 萬 |
| 付費訂閱區的預告貼文 | 750–4,000 |
| 置頂：三輪減半 MVRV 疊圖，回頭驗證當初的預測 | 235 萬 |

他的寫法：

1. **第一句就是一個數字或判斷，而且是口語**：「時隔 2 個月」新買家來到 430 萬顆、Binance 和 Coinbase「冰火兩重天」、「這可能是第 2 次訊號」。不是公告，是一句會讓人停下來的話。
2. **一則一張圖**，圖就是證據；文字只解釋圖上那件事。
3. **自己命名的指標**：賣方衰竭指數、PSIP、BRS、BSS、籌碼集中度、交易所購買力。讀者記得名字，會回來問「BRS 現在多少」。
4. **回扣自己以前的貼文**：常引用自己之前那則（「曾經我在一篇推文中提過」），讓內容串成一個系列，新讀者會一路往回看。
5. **事件發生後幾小時內就有鏈上數字**：幣安被盜、提幣潮、Coinbase 大額轉入，都是當天就出一則。
6. **有個人味**：口語、偶爾講生活（在 OKX 質押「撸個豬腳飯」）、偶爾一句英文短句。
7. 付費區預告的瀏覽只有公開貼文的十分之一，成長靠的是公開的數據貼文。

## wander（@serlo123，約 8,500 粉）

## 我們借用什麼

| 借用 | 怎麼用在 Daybreak |
|---|---|
| 第一句是數字 | 日報貼文 2026-11-05 起改成數字開頭（`docs/CLAUDE_DAILY.md` 步驟 9），成效記在 `ops/log/` |
| 一則一張圖 | 已經在做：日報、快訊、推薦圖表、回覆都配圖 |
| 命名 | Daybreak 自己的指標取固定的名字，見 [`voice.md`](voice.md)「命名」 |
| 回扣自己 | 數字更新到我們以前發過的東西時，用「引用自己那則」來寫，而不是另發一則沒有前文的 |
| 事件快訊 | 已經在做（`data/flash.json`） |
| 問句標題的長文 | 每 2–4 週一篇，題目從 [`content-map.md`](content-map.md) 挑 |

**不借用的**：粗口、政治、「相信自己」這類喊話、@grok 二選一、emoji 堆疊、付費區。和 [`voice.md`](voice.md) 的原則衝突。
